# تقرير حالة ERP مقابل المواصفات (المرحلة A)

**الطريقة:** فحص ساكن للمستودع (شجرة الملفات، مخطط Prisma، الـ Controllers، صفحات الويب) + typecheck + بناء Next.js + اختبارات وحدات الويب.
**لم يُنفَّذ:** اختبارات الـ e2e (11 ملفاً) لأنها تحتاج PostgreSQL ومحرك Prisma غير متاحين في بيئة الفحص. يجب تشغيلها في CI/جهازك قبل الاعتماد على أي ادعاء في الـ README.

## مغطّى في الكود (بحسب البنية والاختبارات المكتوبة، غير مُشغَّل هنا)
شجرة الحسابات والقيود والترحيل والعكس والفترات، المخزون متعدد المخازن بالمتوسط المرجح ومنع السالب (قيد CHECK)، المبيعات والمشتريات والمرتجعات (سليم/تالف) والإلغاء بالعكس، حد الائتمان مع صلاحية `sales:override_credit_limit`، الخزائن والبنوك والسندات والشيكات والتسوية البنكية، أعمار الديون بتسوية FIFO، المناديب والعهدة وإقفال اليومية والعمولات (بمنع التكرار عبر `sourceKey` الفريد)، الموارد البشرية والرواتب، المزامنة بمفاتيح idempotency، RBAC وAudit Log، التقارير وتصدير Excel.

## غير موجود في الكود (بحث في `src` و`prisma`: صفر نتائج)
| المطلوب | الحالة |
|---|---|
| عرض سعر / أمر بيع | غير موجود |
| طلب شراء / أمر شراء / استلام بضاعة منفصل عن الفاتورة | غير موجود |
| جرد مخزني (Stock count) مستقل | غير موجود (يوجد تسوية مخزون `adjustments` فقط) |
| طريقة تقييم FIFO للمخزون | غير موجودة؛ الإعداد `inventory.valuationMethod` مزروع بقيمة `WEIGHTED_AVERAGE` فقط (FIFO الموجود خاص بأعمار الديون) |
| سجل زيارات العملاء / عملاء لم تتم زيارتهم | غير موجود |
| تنبيهات انتهاء الصلاحية / دفعات (Batches) | غير موجود |
| الصلاحية على مستوى الفرع/المخزن | غير موجودة (RBAC على الوحدة/العملية فقط) |
| حماية CSRF | غير موجودة صراحةً (الجلسة بكوكيز httpOnly عبر وكيل same-origin؛ تحتاج مراجعة SameSite) |
| Redis للـ rate limiting | مُجهَّز في compose ولا يُستخدم (حسب README) |
| سندات التقفيل السنوي (قيود إقفال) | يحتاج تحقق: ذُكر "closing" في ملف واحد فقط |

## الحالة الفعلية لما ذُكر في README
- "الويب للقراءة والتقارير فقط": **غير دقيق** — الصفحات تحوي نماذج إنشاء/تعديل وفواتير وسندات وقيود. لكن بعض النماذج كان فيها أخطاء تمنع الحفظ (انظر ملف تدقيق الأزرار).
- تطبيق الموبايل: لم يُجرَّب على جهاز.
